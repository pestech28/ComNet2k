# Requirements
* Any Linux Distro from 2016 and later
# How to install
1. Copy the files of this repo somehow
2. Open the downloaded files folder
3. Open in terminal
4. Run ``` chmod +x ./install.sh ```
5. Run ``` sudo ./install.sh ```
6. in a seperate ttyl or terminal window run ``` cd /var/www/html/live/headlines | sudo python3 headlines.py ```
7. in another seperate ttyl or terminal window run ``` cd /var/www/html/live/forecast | sudo python3 forecast.py ```

# Rules to be added as a pass through
