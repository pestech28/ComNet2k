# Requirements
* Any Linux Distro from 2016 and later
# How to install
1. Copy the files of this repo somehow
2. Open the downloaded files folder
3. Open in terminal
4. Run ``` chmod +x ./install.sh ```
5. Run ``` sudo ./install.sh ```

# Rules to be added as a pass through
1. The site must use Y2K or Frutiger Aero, or a sub aethetic of Y2K or Frutiger Aero web design
2. The website must work on either IE 6/7/8 Firefox 1/2/3/4/5/6 Safari or 1/2/3 Chrome 1
3. If our code is compatible but https is on the server mirroring will be allowed
